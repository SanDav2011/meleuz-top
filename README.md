# Meleuz Top

Оригинальный адаптивный шаблон лендинга для сервиса обмена криптовалюты. Используйте его как основу и замените все тексты, контакты, курсы, логотип и юридическую информацию на собственные.

## Что заменить

- Название `MELEUZTOP` в `index.html`.
- Тексты hero-блока, преимуществ, аудиторий и FAQ.
- Курсы в объекте `rates` в `script.js`.
- Контакты в разделе `#contacts`.
- Тексты дисклеймеров и юридическую информацию.

## Запуск

Откройте `index.html` в браузере или разместите файлы на любом статическом хостинге: GitHub Pages, Netlify, Vercel и других.

## Важно

Это шаблон, а не копия существующего сайта. Не используйте чужие логотипы, тексты, изображения и фирменные элементы без разрешения правообладателя.
